📱 Installation sur Mobile

iOS (Safari) : Appuyez sur le bouton "Partager" puis "Sur l'écran d'accueil".
Android (Chrome) : Menu ⋮ → "Ajouter à l'écran d'accueil" ou bannière d'installation automatique.

L'application fonctionne entièrement hors-ligne une fois installée. Vous pouvez aussi télécharger le fichier HTML pour le partager.

💡 Sans serveur local (iPhone/Android) :

  1. Cliquez sur "COPIER LE CODE".
  2. Ouvrez l'app Notes ou un éditeur de texte sur votre téléphone.
  3. Collez le contenu et enregistrez sous le nom index.html.
  4. Ouvrez ce fichier dans Safari ou Chrome. L'app est autonome et ne nécessite pas Internet.
